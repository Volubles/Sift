# Sift identity assets

The mark combines a waveform S with the lowercase wordmark `sift.`. The SVG
files contain editable paths and shapes, without external fonts or embedded
images. Each variant uses one solid color and a transparent background.

| Background | SVG master | PNG export |
| --- | --- | --- |
| Dark | [White](sift-logo-white.svg) | [White PNG](sift-logo-white.png) |
| Light | [Black](sift-logo-dark.svg) | [Black PNG](sift-logo-dark.png) |

PNG exports are 1200 × 1200 pixels and use the same geometry as their SVG
masters. Edge smoothing uses alpha; the visible fill color stays uniform.
Use the SVG where scalable artwork is supported, and preserve its aspect ratio.
